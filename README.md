# D404 实验室值日看板

一个**手机/电脑都能打开**的值日看板网页。管理员在本地修改值日人员、提醒时间、节假日、消息模板后，**一键生成纯静态网页**（`dist/`），部署到 GitHub Pages / Cloudflare Pages / 学校服务器即可获得一个公网链接，发到微信群「D404实验室」里大家点开就能看。

> ⚠️ 本版本**不接微信机器人、不使用 wxauto、不控制微信客户端、不自动发群**。看板只负责展示 + 一键复制提醒文字，管理员**手动**把复制的内容转发到微信群。

---

## 一、它做什么 / 不做什么

| 能力 | 说明 |
|------|------|
| ✅ 公共看板 | 手机/电脑浏览器打开，看今天/明天/本周/下周值日、节假日暂停、提醒时间 |
| ✅ 一键复制 | 复制今日/明日/本周安排/群公告，粘贴到微信群 |
| ✅ 浏览器提醒 | 网页打开时，到点弹浏览器通知（需授权） |
| ✅ PWA | 手机可「添加到桌面」 |
| ✅ 本地管理 | 改值日人员/时间/节假日/模板，生成静态发布文件 |
| ❌ 自动发微信群 | 不做。复制后由人转发 |

## 三、安装

环境：**Windows + Python 3.10+**。

双击 `install.bat`，自动建虚拟环境并安装 Flask。看到「安装完成」即成功。

手动方式：
```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 四、启动本地管理页面

双击 `start.bat`，自动打开浏览器：

- 公共看板预览： **http://127.0.0.1:8848**
- 管理后台： **http://127.0.0.1:8848/admin**

关闭命令行窗口即停止。

## 五、修改值日人员

进入 **管理后台 → 值日人员**（`/admin/duty`）：

- 修改组名、负责人、周一到周五值日人；
- 「+ 新增小组」自动分配组号并加入循环；
- 「删除该组」会从循环顺序中移除。

轮换基准在 **基础设置** 页：

- `基准周周一日期`（base_monday）：标注「这一周属于第几组」的参考周；
- `组循环顺序`（order）：默认 `2,3,1`，即 第2组→第3组→第1组→第2组…
- 当前默认：`2026-06-15`（本周周一）为 **第2组（王子月组）**。

---

## 六、修改提醒时间

进入 **管理后台 → 提醒时间**（`/admin/reminders`）：

- 工作日（周一到周五）可添加多个时间，每个可启用/禁用；
- 周六大扫除可整体开关，也支持多个时间；
- 周日提醒、倒计时显示、提醒前提示分钟数可配置。

> 这些时间**只影响网页展示和复制文案**，不会自动发消息。

---

## 七、设置节假日和课题组放假

进入 **管理后台 → 节假日**（`/admin/holidays`）：

- 填名称、类型（法定节假日 / 课题组放假）、起止日期，点「添加」；
- 列表支持「编辑」「删除」。

默认已内置 2026 年主要节假日（元旦、春节、劳动节、端午节、国庆节）与「课题组暑假放假」示例，可随时改。

> 节假日与放假**只影响页面提示**，**不改变三组轮换顺序**。

---

## 八、消息模板

进入 **管理后台 → 消息模板**（`/admin/templates`）：

- 工作日模板变量：`{date}` `{weekday}` `{group_name}` `{leader}` `{duty_person}` `{chat_name}`
- 周六模板变量：`{date}` `{weekday}` `{group_name}` `{leader}` `{chat_name}`
- 点「用今天渲染预览」看实际效果，再「保存模板」。

---

## 九、生成发布文件

进入 **管理后台 → 基础设置**（`/admin`），底部「📦 生成 / 更新发布文件」：

1. 点按钮，生成 `dist/` 文件夹（`index.html` + `data/` + `static/`）；
2. 点「打开 dist 预览」在本地确认效果；
3. 把 `dist/` 内容部署到任意静态托管平台。

每次修改配置后，重新点「生成」并重新部署即可更新看板。

## 十、部署 dist 到公网

### 方式 A：GitHub Pages（免费、稳定）
1. 在 GitHub 新建仓库（如 `d404-duty`）。
2. 把 `dist/` 里的**所有文件**放进仓库根目录（或 `docs/`），提交并推送。
3. 仓库 **Settings → Pages → Source** 选对应分支和目录，保存。
4. 等待 1~2 分钟，得到链接 `https://你的用户名.github.io/d404-duty/`。

### 方式 B：Cloudflare Pages（快、不限流量）
1. Cloudflare 控制台 → Pages → 创建项目。
2. 直接上传 `dist` 目录，或连接 GitHub 仓库指向 `dist`。
3. 部署完成得到 `https://xxx.pages.dev` 链接。

### 方式 C：学校服务器
1. 把 `dist/` 内所有文件拷到 Web 服务器静态目录（如 nginx 的 `html/d404/`）。
2. 访问 `https://学校域名/d404/`。

### 方式 D：临时本地分享
双击 `dist/index.html` 可在本机浏览器打开（仅本机可见，不能给群友用）。

## 十一、把链接发到微信群 / 设为群公告

1. 部署后复制公网链接（如 `https://xxx.github.io/d404-duty/`）。
2. **发到群**：在微信群「D404实验室」直接粘贴链接发送。
3. **设为群公告**：微信群右上角 `…` → 群公告 → 编辑 → 粘贴链接 → 发布。
4. 群友点链接即可打开看板（手机浏览器或微信内置浏览器均可）。

> 想让群友手机桌面有图标：用浏览器（Safari/Chrome）打开链接 → 分享 → 「添加到主屏幕」，之后像 App 一样打开（PWA）。

## 十二、为什么这个版本不需要微信机器人

- **稳定**：微信机器人（wxauto 等）依赖模拟点击，受微信版本/弹窗影响，容易失败；纯网页看板没有这个风险。
- **省事**：管理员无需常开电脑、无需保持微信登录，部署一次长期可用。
- **合规**：不触碰任何人的微信客户端，不自动发消息，避免打扰。
- 管理员每天点开看板 → 「复制今日提醒」 → 粘贴到群，3 秒完成，和自动发群效果几乎一样，但完全可控。

## 十三、浏览器提醒功能的限制

- 看板内置「开启浏览器提醒」按钮：授权后，**网页保持打开期间**会在提醒时间弹出浏览器通知。
- ⚠️ **网页关闭后无法提醒**（浏览器限制）。要稳定到点提醒，请保持看板页面开着，或仍由管理员手动转发。
- 手机上「添加到主屏幕」后，仍需打开页面才会提醒；这不是后台推送服务。
- 若要真正的后台推送（即使关页面也提醒），需要配置 Web Push 服务 + 服务器，本版本未包含。

## 十四、复制文案说明

看板和基础设置页提供四类复制内容，均适合直接粘贴微信群：

- **复制今日提醒**：今天的工作日/大扫除模板（按今天日期渲染）；
- **复制明日提醒**：明天的模板；
- **复制本周安排**：本周周一到周六值日一览（含暂停标注）；
- **复制群公告**：适合发成群公告的精简版（本周组别 + 周一到周五人员）。

## 十五、常见问题

**Q：部署后页面空白 / 数据不显示？**
- 确认 `dist/data/` 下 4 个 JSON 都已上传（config / duty_groups / skip_days / templates）；
- 确认 `dist/static/` 下 style.css、public.js、manifest.json 都在；
- 用相对路径部署（不要改文件之间的相对位置）。

**Q：GitHub Pages 子路径下样式丢失？**
- 本看板用相对路径，理论兼容 `/repo/` 子路径。若仍异常，把 dist 内容放仓库根目录部署到 `用户名.github.io` 顶层域名最稳妥。

**Q：今天显示「暂停」？**
- 今天可能落在节假日或课题组放假区间。看板会显示原因和「下一个值日日」。

**Q：修改后群友看到的没更新？**
- 改完要重新「生成发布文件」并重新部署；浏览器可能有缓存，强刷（Ctrl+F5）或换无痕窗口。

**Q：换电脑配置丢失？**
- 备份 `data/` 目录即可完整迁移。重新「生成发布文件」再部署。

## 十六、轮换算法（便于核验）

设 `base_monday` 为基准周周一，`order` 为循环顺序（如 `[2,3,1]`）：

1. 把目标日期对齐到当周周一 `target_monday`；
2. `weeks = (target_monday - base_monday) 天数差 // 7`；
3. `组号 = order[weeks % len(order)]`。

本周值日人 = 该组成员列表中 `星期几-1` 对应的人（周一=index0 … 周五=index4）。周六显示该组负责人组织大扫除；周日显示「无固定值日」。
